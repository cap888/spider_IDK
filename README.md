# Spider Robot — шестилапый робот на Arduino

Автономный шестилапый робот на Arduino Uno с 12 сервоприводами Feetech FS90.
Управление сервоприводами выполняется через Амперка Multiservo Shield v2 по I2C.

Текущая прошивка по умолчанию находится в безопасном режиме проверки сервоприводов (`SERVO_TEST_MODE`): автономная походка не запускается, каналы 0–11 проверяются по одному небольшим отклонением от центра.

## Что умеет

- 6 лап, 12 сервоприводов Feetech FS90: 2 сервопривода на лапу
- Управление через Амперка Multiservo Shield v2 по I2C
- Безопасный тест каналов перед первым запуском механики
- Автономная последовательность движений после отключения тестового режима
- Tripod gait: чередование двух троек лап
- Плавное движение сервоприводов через собственный слой `ServoController`
- Обратная кинематика для 2-суставной лапы

## Важно про Multiservo Shield v2

Амперка Multiservo Shield v2 — это не PCA9685-плата.

Шилд использует собственный микроконтроллер ATmega48PA и общается с Arduino по I2C.
Стандартный адрес библиотеки Multiservo: `0x47`.

Схема управления:

```text
Arduino Uno
  -> I2C A4/A5
Amperka Multiservo Shield v2, ATmega48PA, address 0x47
  -> PWM-выходы каналов 0–17
Feetech FS90, используются каналы 0–11
```

В проекте используется библиотека `Multiservo`, а не `Servo.h` и не PCA9685-драйвер.

## Аппаратное обеспечение

- Arduino Uno
- Амперка Multiservo Shield v2
- 12 × Feetech FS90
- Внешнее питание сервоприводов 5 В
- BEC не ниже 5 В 3 А для первичных тестов
- Общая земля между Arduino, шилдом и питанием сервоприводов

Не питать 12 сервоприводов от пина 5V Arduino.

## Библиотеки Arduino

Установить через Arduino Library Manager или GitHub:

- `Multiservo` от Амперки: https://github.com/amperka/Multiservo

Встроенные библиотеки Arduino:

- `Wire.h`
- `math.h`

`ServoSmooth` в проекте сейчас не используется. В коде уже есть собственное сглаживание движения: `current_angles`, `target_angles`, `servo_speeds` и периодический `ServoController::update()`. Библиотека ServoSmooth рассчитана на обычный `Servo.h` или PCA9685-режим, поэтому напрямую не является подходящим драйверным слоем для Amperka Multiservo Shield v2.

## Безопасный первый запуск

По умолчанию включён тестовый режим:

```cpp
#define SERVO_TEST_MODE
#define SERVO_TEST_STEP_ANGLE 15
#define SERVO_TEST_HOLD_MS 400
```

Режим находится в `receiver/Config.h`.

Поведение теста:

1. Автономная походка отключена.
2. Шилд и сервоприводы инициализируются.
3. Каждый канал 0–11 по очереди получает команды:
   - центр: 90°
   - плюс: 105°
   - минус: 75°
   - центр: 90°
4. Между фазами пауза 400 мс.
5. После канала 11 тест завершается.

Это нужно для проверки:

- правильного номера канала
- направления вращения
- питания сервоприводов
- отсутствия упора в механику
- перепутанных разъёмов

## Загрузка прошивки

1. Установить библиотеку `Multiservo`.
2. Открыть `receiver/receiver.ino` в Arduino IDE.
3. Выбрать плату `Arduino Uno`.
4. Выбрать порт Arduino.
5. Загрузить прошивку.
6. Открыть Serial Monitor на скорости `115200 baud`.

Ожидаемый вывод в тестовом режиме:

```text
Spider Robot Starting...
Hardware: Arduino UNO + Amperka Multiservo Shield v2
Servos: 12x Feetech FS90
SERVO_TEST_MODE enabled: autonomous gait is disabled
Test channel 0: center
Test channel 0: plus
Test channel 0: minus
...
Servo test complete
```

## Как включить автономную походку

Только после успешной проверки каналов и механики закомментировать строку в `receiver/Config.h`:

```cpp
// #define SERVO_TEST_MODE
```

После этого при включении робот выполнит автономную последовательность.

## Автономная последовательность

После отключения `SERVO_TEST_MODE` робот выполняет:

1. Задержка 2 секунды, встроенный LED мигает с частотой 3 Гц.
2. 3 шага вперёд.
3. Пауза 0.5 секунды.
4. 3 шага назад.
5. Пауза 0.5 секунды.
6. 3 стрейфа влево.
7. Пауза 0.5 секунды.
8. 3 стрейфа вправо.
9. Поворот 360° против часовой стрелки.
10. Стоп.

## Архитектура управления

```text
receiver.ino
  -> RobotController::update()
    -> processServoTest(), если включён SERVO_TEST_MODE
    -> processSequence(), если тестовый режим выключен
      -> GaitEngine::update(dx, dy)
        -> LegKinematics::inverseKinematics(x, y)
          -> ServoController::setLegAngles()
            -> ServoController::update()
              -> Multiservo.write(angle)
                -> Multiservo Shield v2
```

## Походка Tripod

Лапы разделены на две группы:

- группа A: лапы 0, 2, 4
- группа B: лапы 1, 3, 5

В одной фазе группа A находится в swing-фазе, группа B — в stance-фазе. Во второй фазе группы меняются местами.

В коде есть инициализация стартовой фазы tripod gait, чтобы при старте не получить состояние, где все лапы считаются опорными.

## Плавность движения

Текущая плавность реализована в `ServoController.h` без внешней библиотеки:

```cpp
current_angles[channel]
target_angles[channel]
servo_speeds[channel]
```

Каждый вызов `update()` ограничивает изменение угла максимальной скоростью `SERVO_MOVE_SPEED`.
Профиль движения сейчас линейный: без отдельного ускорения и торможения.

Если понадобится более мягкая походка, лучше расширять этот слой ускорением поверх `Multiservo`, а не заменять драйвер на `ServoSmooth`.

## Устранение проблем

### Сервоприводы не двигаются

- Проверить внешнее питание сервоприводов на шилде.
- Проверить общий GND.
- Проверить, что установлен Multiservo Shield v2.
- Проверить установку библиотеки `Multiservo`.
- Проверить каналы 0–11 в `SERVO_TEST_MODE`.

### Двигается не тот сервопривод

- Сверить физический разъём с номером канала.
- Один канал соответствует одному объекту `Multiservo`.
- Лапа N использует каналы `N * 2` и `N * 2 + 1`.

### Сервопривод движется в опасную сторону

- Отключить питание.
- Не запускать автономную походку.
- Исправить калибровку в `INITIAL_POSITIONS`.
- При необходимости изменить инверсию/геометрию в кинематике.

### Робот не выполняет автономную последовательность

- Проверить, не включён ли `SERVO_TEST_MODE`.
- Пока `SERVO_TEST_MODE` включён, автономная походка намеренно отключена.

## Безопасность

- Первый запуск выполнять только в `SERVO_TEST_MODE`.
- Лучше начинать с отсоединённой механики или поднятого робота.
- Проверять каждый канал по одному.
- Не ставить робота на пол до проверки направления всех сервоприводов.
- Следить за просадкой питания и нагревом BEC.
- Для полной походки 5 В 3 А может быть нижней границей, особенно если механика тугая.
